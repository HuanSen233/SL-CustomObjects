# 曲线工具（Curve Tool）

> 在 Unity 场景中像 Blender 一样绘制贝塞尔曲线，并**沿曲线一键生成物体**。
> 面向普通用户；开发者文档见 [README_CurveTool_DEV.md](./README_CurveTool_DEV.md)。

---

## 一、这是什么？

曲线工具是一个 Unity **编辑器工具**，让你在场景视图中：

- 🎯 **绘制贝塞尔曲线**：自由放置顶点、拖拽控制柄，支持 2D 平面曲线与 3D 空间曲线
- ✏️ **精细编辑**：5 种 Blender 风格控制柄类型、分轴锁定、网格吸附、多选批量移动
- 🧱 **沿曲线生成物体**：每个小线段独立设置物体类型（球/胶囊/圆柱/立方体/平面/四边形）、缩放、偏移与旋转，一键生成整条曲线上的物块
- 💾 **数据保存在场景中**：曲线随场景保存（Ctrl+S），每个场景拥有独立的曲线组

## 三、打开工具

菜单栏：**Tools → Curve Tool**（窗口标题：Curve Tool / 曲线工具）。

---

## 四、快速上手（5 步）

1. 打开 **Tools → Curve Tool** 窗口
2. 在 **编辑** 页签点击 **曲线编辑** 按钮（变绿 = 已开启编辑模式）
3. 在 **曲线列表** 输入名称 → 点 **2D** 或 **3D** 按钮创建曲线
4. 在场景视图中选中顶点/控制柄，拖拽调整形状（见下文操作表）
5. 点击 **生成物体** 沿曲线生成物块（可先开 **预览** 查看线框）

## 五、窗口界面说明

### 编辑页签（从上到下）

| 区块 | 功能 |
|---|---|
| **曲线编辑** 开关 | 开启后才能在场景视图操作曲线（开启时按钮变绿） |
| **曲线工具** | 翻转 X/Y/Z、镜像 X/Y/Z（以原点或游标为中心）、游标参考系开关、游标位置（带分轴锁）/ 锁定 / 重置 |
| **曲线列表** | 新建行（名称 + 段数 + 2D/3D 按钮）；每行：选择 ○、显示 D、启用 E、锁定 L、名称、轴向、段数、闭环 R、复制 C、删除 ✕；底部可"删除全部曲线" |
| **顶点与控制柄属性** | 选中顶点的位置（分轴锁）、控制柄类型、左/右控制柄位置（分轴锁） |
| **选中段属性** | 选中小线段的基础物体类型、基础缩放、中心点偏移、适应段长、相对缩放、旋转偏移、位置偏移（可批量作用于多段） |
| **物体生成** | 物体颜色、**生成物体** 按钮、**预览** 开关 |

### 设置页签

| 分组 | 选项 |
|---|---|
| 尺寸 | 顶点尺寸、控制柄尺寸、箭头尺寸（3D 高度箭头） |
| 吸附 | 网格吸附步长（XYZ）、增量吸附步长（XYZ） |
| 颜色 | 顶点颜色、控制柄端点颜色 |
| 语言 | English / 简体中文（即时切换） |
| 其他 | 重置为默认值 |

## 六、场景操作指南

| 操作 | 效果 |
|---|---|
| **左键点击** 顶点/控制柄 | 选中并拖拽移动 |
| **左键点击** 小线段中点 | 选中该分辨率线段（可改段属性） |
| **Alt + 左键** 曲线段 | 选中整条贝塞尔跨度（该段所有小线段） |
| **Shift + 左键** | 追加选中（多选顶点后拖拽可整体移动） |
| **Alt + 右键** 曲线段 | 在曲线上插入新顶点 |
| **Ctrl + 右键** 端点 | 从端点延伸新顶点 |
| **Delete** | 删除选中顶点（每条曲线至少保留 2 个顶点） |
| **Ctrl（或 Cmd）+ 拖拽** | 使用"增量吸附"步长；普通拖拽使用"网格吸附"（或开启 Unity 的 Snap Settings 网格吸附） |

> 提示：曲线被 **锁定**（L）后顶点变橙色且不可编辑；被 **隐藏**（D）后在场景中不显示。

### 控制柄类型（Blender 风格）

| 类型 | 说明 |
|---|---|
| **自动 Auto** | 两端自动对齐，随相邻顶点自动调整角度与长度 |
| **对齐 Aligned** | 方向对称（左右反向），长度各自独立 |
| **镜像 AlignedLength** | 方向与长度完全镜像（右柄 = -左柄） |
| **矢量 Vector** | 控制柄指向相邻顶点，段间为直线 |
| **自由 Free** | 完全自由，无约束 |

> 拖拽"自动/矢量"控制柄时会自动切换为"自由"，避免自动计算覆盖你的手动调整。

### 分轴锁定（L 按钮）

顶点位置、控制柄位置、游标位置旁都有 **L** 按钮：锁定后该轴拖拽不变（按钮变橙色），数值输入框被禁用。用于精准单轴调整。

## 七、生成物体详解

1. **选中一条曲线**（列表中点击 ○ 或场景中选中顶点）
2. 依次点击小线段（或 Alt+左键选整段）→ 在 **选中段属性** 中设置：
   - **基础物体**：球体 / 胶囊体 / 圆柱体 / 立方体 / 平面 / 四边形
   - **基础缩放**：物块绝对尺寸
   - **适应段长**：勾选后把该小线段长度乘到指定缩放轴（X/Y/Z），物块自动"贴"满每段
   - **相对缩放**：在基础缩放基础上再乘一个倍率
   - **中心点偏移 / 位置偏移 / 旋转偏移**：沿段方向的偏移与旋转微调
3. 点 **生成物体** → 生成物块挂载到 `曲线生成_{曲线名}` 父对象下

> 💡 **预览**：勾选 **预览** 后场景中显示物块线框，所见即所得（与生成结果完全一致）。

## 八、数据保存说明（重要）

- **曲线数据保存在当前场景中**：编辑后按 **Ctrl+S** 保存场景，曲线随场景文件一起保存；下次打开场景自动恢复。
- 每个场景的曲线组相互独立。
- 曲线数据载体为场景中一个隐藏对象（`__CurvesToolData__`），无需手动管理。
- 工具设置（颜色/尺寸/语言/吸附）保存在工具目录的 `CurveToolSettings.json`，与场景无关，全局生效。

## 九、常见问题（FAQ）

**Q：场景视图中点不动曲线？**
A：确认工具窗口已打开且 **曲线编辑** 开关为绿色。

**Q：生成的物体位置和预览不一致？**
A：预览与生成共用同一套计算，理论上完全一致；请确认没有修改过段属性后忘记刷新（预览勾选状态）以及曲线未隐藏。

**Q：为什么有些段没有生成物体？**
A：过短的段（长度 < 0.001）会被自动跳过，避免零尺寸物块。

**Q：删除了隐藏的 `__CurvesToolData__` 对象？**
A：重新打开工具会自动重建（空数据）；若此前保存过场景，可重新加载场景恢复。

**Q：设置乱了想恢复？**
A：设置页签 → **重置为默认值**。

**Q：想删掉某条曲线？**
A：曲线列表该行右侧 **✕** 删除单条；底部 **删除全部曲线** 清空当前场景所有曲线（有确认弹窗）。
